## 二、新增条目（6 条）

| 编号 | 标题 | 分类 | 新增理由 |
|---|---|---|---|
| KB-API-014 | ProjectKB.stats 与 related_entries | api | v2.0 新增的统计与导航方法此前无条目，知识库无法自述健康度 |
| KB-DATA-007 | 知识库元信息与字段规范元数据 | data | `schema_version`、`field_spec`、`categories` 三个元信息块未文档化 |
| KB-ERR-005 | 知识库校验错误码表 | error | 校验失败时缺按码定位的排障表，只能逐条读中文 |
| KB-CONV-006 | 文档构建规范（Markdown 转 Word） | convention | 分块、禁用结构、失败重建三条经验未沉淀，每次生成文档重新踩坑 |

| KB-GUIDE-007 | 检索权重与调优规则 | guide | 打分权重与阈值不透明，检索异常时只能猜 |

新增条目均按既有规范归档：`category` 取既有 11 类之一，`version` 标注 `>=2.1.0`，`tags` 3~4 个，`related` 与既有条目双向闭合。

## 五、索引同步

数据变更后新增倒排索引，避免"改了数据但检索仍走旧结构"：

| 能力 | 实现 |
|---|---|
| 索引文件 | `data/kb_index.json`，记录源数据 sha256 与构建时间 |
| 构建 | `python tools/rebuild_index.py`（2070 个索引词） |
| 加载校验 | 哈希一致才启用倒排表，否则标记 stale 并退回线性扫描 |
| 一致性 | 抽样 5 组查询，索引检索与线性检索 Top3 完全一致 |
| 校验集成 | `verify_kb.py` 新增 INDEX_MISSING / INDEX_STALE 检查 |
